## Publish

1. Extract this ZIP. Keep index.html and the assets/media folders together.
2. Create a GitHub repository and upload or commit the extracted contents at its root (index.html must be at the repository root, not inside another enclosing folder). Include the .nojekyll file.
3. In repository Settings → Pages, choose Deploy from a branch, then main and / (root), and Save.
4. Open the Pages URL shown by GitHub after deployment. Repository subfolder URLs are supported.

GitHub instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

No npm install, Node server, or build is needed for this exported copy. You can also open index.html directly to preview it.

The animation, latest saved information, embedded images, and referenced uploaded videos are included. YouTube/Vimeo and other external video links still need access to their original services. information.html is a separate reading copy. content.json can be imported into the local Information studio.

This published site is read-only. Keep the original local project to use its editor, then export again and replace these files when the content changes. Passwords, databases, backups, and the editor server are deliberately excluded.

Retain SOURCES.md and the licence files in assets when publishing; the anatomical meshes are adapted from Z-Anatomy / BodyParts3D under CC BY-SA 4.0.
